## Example FI-MM Flow

### Goods Receipt

```text
Dr Inventory / Expense
    Cr GR/IR Clearing
```

### Supplier Invoice

```text
Dr GR/IR Clearing
Dr Recoverable Input Tax, where applicable
    Cr Supplier
```

### Payment

```text
Dr Supplier
    Cr Bank
```

These are simplified learning examples. Actual accounting treatment depends on configuration, valuation, account assignment, tax, and transaction circumstances.
